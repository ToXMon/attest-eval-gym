ATTESTAppendix / scope and operating notes

Be precise about what is measured

Implemented scope

  • Vultr model → ATTEST coding loop → Python execution.
  • Deterministic outcome grading and limited containment classification.
  • SHA-256 ledger and OTLP/JSON export.

Proposed, not implemented

A full BYO-agent adapter. No claim of containing an external agent's tools, state, or local actions.

Known limits

Estimated costs; classifier-derived P(safe); reconstructed task-span timing; no verified Phoenix import.

Rootful Docker remains a privilege boundary. In-memory admission/spend counters are not an account-wide billing cap.

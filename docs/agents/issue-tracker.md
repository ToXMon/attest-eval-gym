# Issue tracker: GitHub Issues

Issues for this repo live in GitHub Issues on `ToXMon/attest-eval-gym`, managed with the `gh` CLI (`gh issue create`, `gh issue list`, `gh issue edit --add-label`, `gh issue close`).

- **PRs as a request surface**: off.
- Tracer-bullet tickets for the eval-gym build are labeled `eval-gym` and carry blocking edges as `blocked-by #N` in the body.
